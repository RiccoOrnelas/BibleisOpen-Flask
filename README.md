# BibleisOpen - Devocionais

Este é um projeto de blog para devocionais. Nele, os usuários podem visualizar devocionais disponíveis, bem como criar e publicar os seus próprios para a comunidade.

## Tecnologias Utilizadas

- **Flask**: Framework web em Python.
- **SQLAlchemy**: ORM para interagir com o banco de dados.
- **Jinja2**: Motor de template usado para gerar as páginas HTML.
- **SQLite**: Banco de dados relacional para armazenar os dados.
- **Flask-Login**: Extensão para gerenciar a autenticação dos usuários
